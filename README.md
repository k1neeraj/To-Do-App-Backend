# To-Do-App-Backend

This is the backend API server for the To-Do App, built with Node.js, Express, and MongoDB.  
It provides RESTful endpoints to create, read, update, and delete to-do tasks.

## Features

- CRUD operations for to-do items
- Uses MongoDB for data storage
- Simple and clean REST API
- CORS enabled for frontend integration

## Tech Stack

- Node.js
- Express.js
- MongoDB (Mongoose)
- dotenv for environment configuration
- CORS middleware
